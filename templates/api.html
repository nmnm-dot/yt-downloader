API

Local only. Mutating requests need the header X-Requested-With: yout-local.

GET /api/info?url=Title, duration, thumbnail, available heights, subtitle languages (or playlist entries).
GET /api/search?q=YouTube search (12 results).
GET /api/suggest?q=Search suggestions.
POST /api/jobsStart a conversion. JSON: url, format (mp3|mp4|wav|gif), quality, start, end, title, artist, remove_silence, normalize, discover_metadata, h264, subtitles, subtitle_language.
GET /api/jobs/<id>Status, progress (0–100), error.
GET /api/jobs/<id>/fileDownload the finished file.
GET /api/downloadsFiles already in the downloads folder.
GET /watch?v=IDShortcut to the converter page.
